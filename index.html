Admin Dashboard

A quick view of successfully processed worker reports for one selected day. Only processed submissions are included; pending and rejected reports are excluded. For structured worker submissions, the exact saved local values from the submission are the dashboard source of truth.

Process Worker Report

Multiple submissions on the same date are accumulated under the same worker/day. Accepted date formats: 7 August, 7th August, August 7, August 7th. GrabPoints, Zoombucks, Super Pay Me, Branded Surveys, Paidwork and TimeBucks are treated as USD sources and converted to the ID's local currency. The date is taken from the WhatsApp report itself. After processing, the worker can delete an individual submitted report or all reports for that day.

Important: Earlier builds had date/report-count bugs. New reports use the WhatsApp report date; existing test records saved under the wrong date are not silently moved.

⬇️ Download Backup

Creates a complete local SurveyHub data file, including reports, worker submissions, payroll/payment tracking, withdrawals, reversals, workers, systems, passwords, profiles, shared-database settings and the activity log.

⬆️ Restore Backup

Select a SurveyHub backup file to restore your previous data. Build 173 validates the file first and keeps an automatic in-memory safety copy so a failed restore can roll back to the data that was on this device.

☁️ Shared Database

Connect SurveyHub to one shared Supabase database so worker submissions, admin approvals, processed earnings and the Activity Log are visible across different phones/computers.

Configure the same Project URL, Anon Key and Workspace ID on every device that should share SurveyHub data.

Backup note: Build 174 synchronizes the Activity Log as well as reports. Press Sync Now before downloading so the backup includes shared activities pulled from other admin devices.

🧹 Start Live / Clear Test Data

Use this once when testing is finished. It clears test reports, worker submissions, payroll history/payment statuses, withdrawals, reversals and test Activity Log entries from this device and the shared database.

Preserved: workers, systems/IDs, worker/admin passwords, rates, admin accounts, survey profiles, assignments and shared-database connection.

Important: Restoring a backup replaces the current SurveyHub data stored on this device with the data contained in the backup.
